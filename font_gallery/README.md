## 🎨 配色方案

本次展示使用简约风格配色：

- **背景色**: `#F8F9FA` (浅灰)
- **文字色**: `#2C3E50` (深灰蓝)
- **插画透明度**: `0.08`

这种配色方案：
- ✅ 视觉舒适、不刺眼
- ✅ 突出文字内容
- ✅ 专业感强
- ✅ 适合长时间阅读

## 📝 如何使用

### 在图片生成API中使用

```json
{
  "text": "您的文字内容",
  "width": 800,
  "height": 600,
  "fontSize": 48,
  "color": "#2C3E50",
  "backgroundColor": "#F8F9FA",
  "fontFile": "chinese111.ttf",
  "useIllustration": true,
  "illustrationOpacity": 0.08
}
```

### 字体选择建议

1. **标题类内容**: 选择粗壮有力的字体（chinese111、MaoKenShiJinHei）
2. **正文类内容**: 选择清晰易读的字体（chinese、ZiTiQuanWeiJunHei）
3. **装饰类内容**: 选择个性鲜明的字体（PingFangLaiJiangHuFeiYangTi、YunFengFeiYunTi）

---

## 📌 注意事项

1. **字体数量**: 单张图片建议使用不超过2种字体
2. **字体搭配**: 标题用粗体，正文用细体
3. **可读性**: 优先考虑清晰易读的字体
4. **风格统一**: 同一系列内容使用相同字体风格
