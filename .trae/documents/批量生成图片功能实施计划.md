# 图片接口批量生成功能实施计划

## 需求分析

为图片生成接口添加批量生成功能：
- 支持用户传入数组参数
- 根据数组长度生成对应数量的图片
- 返回图片URL数组

## 当前代码结构

### 现有接口
- **路由**: `POST /api/text-to-image` (在 `src/routes/imageRoutes.ts`)
- **控制器**: `textToImageHandler` (在 `src/controllers/imageController.ts`)
- **服务层**: `ImageService` 类已实现 `batchTextToImage` 方法 (在 `src/services/imageService.ts`)

### 现有类型定义
- `TextToImageRequest`: 单个图片生成请求参数
- `TextToImageResponse`: 单个图片成功响应
- `ImageData`: 图片数据结构

## 实施步骤

### 1. 扩展类型定义 (`src/types/request.types.ts`)

添加批量请求类型：
```typescript
// 批量文字转图片请求参数
export interface BatchTextToImageRequest {
  items: TextToImageRequest[];
}
```

### 2. 扩展响应类型 (`src/types/response.types.ts`)

添加批量响应类型：
```typescript
// 批量文字转图片成功响应
export interface BatchTextToImageResponse extends BaseResponse {
  success: true;
  data: ImageData[];
}

// 批量操作的部分成功响应
export interface PartialSuccessResponse extends BaseResponse {
  success: boolean;
  data: {
    successCount: number;
    failedCount: number;
    results: (ImageData | { error: string; message: string })[];
  };
}
```

### 3. 添加批量生成控制器 (`src/controllers/imageController.ts`)

创建新的控制器方法：
```typescript
export async function batchTextToImageHandler(
  request: Request,
  response: Response,
  _next: NextFunction
): Promise<void>
```

功能：
- 验证请求参数是否为数组
- 调用 `ImageService.batchTextToImage` 方法
- 返回图片URL数组
- 处理部分成功的情况

### 4. 添加批量生成路由 (`src/routes/imageRoutes.ts`)

添加新路由：
```typescript
router.post('/text-to-image/batch', batchTextToImageHandler);
```

### 5. 修改现有接口支持两种参数格式

修改 `textToImageHandler` 或创建统一的处理函数：
- 检测参数是单个对象还是数组
- 如果是数组，调用批量处理逻辑
- 如果是单个对象，保持现有逻辑

## 实施细节

### 参数验证逻辑
```typescript
// 检测是否为数组
if (Array.isArray(request.body)) {
  // 批量处理
} else if (typeof request.body === 'object') {
  // 单个处理
} else {
  // 参数错误
}
```

### 响应格式

**单个图片响应**（保持不变）:
```json
{
  "success": true,
  "data": {
    "url": "http://localhost:3000/images/xxx.png",
    "relativeUrl": "/images/xxx.png",
    "width": 800,
    "height": 600,
    "format": "png",
    "fontUsed": "xxx.ttf",
    "fontName": "xxx",
    "illustrationUsed": "xxx.png"
  }
}
```

**批量图片响应**:
```json
{
  "success": true,
  "data": [
    {
      "url": "http://localhost:3000/images/xxx1.png",
      "relativeUrl": "/images/xxx1.png",
      ...
    },
    {
      "url": "http://localhost:3000/images/xxx2.png",
      "relativeUrl": "/images/xxx2.png",
      ...
    }
  ]
}
```

### 错误处理
- 单个图片生成失败不影响其他图片
- 返回每个图片的生成状态
- 记录失败的详细原因

4. **错误处理完善**: 批量操作支持部分成功
